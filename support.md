# DVC Copilot Support

For support, questions, or feedback, open **About DVC Copilot → Send feedback** in the app, or open an issue on this GitHub repository:

https://github.com/larryreeve/dvc-copilot/issues

When reporting a problem, include what you were trying to do, what happened, and your app version. GitHub issues are public; do not include personal or sensitive information. In-app feedback does not collect a reply address, so use GitHub if you want to follow a response.

DVC Copilot provides point estimates for planning. It does not check live availability or make reservations. Confirm final points and booking details with Disney Vacation Club.

DVC Copilot is an unofficial planning app and is not affiliated with, sponsored by, or endorsed by Disney or Disney Vacation Club.
